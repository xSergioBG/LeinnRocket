# Leinn Rocket

Minijuego de navegador construido con Canvas y JavaScript en un único [index.html](index.html).

## Jugar

Descarga el repositorio y abre `index.html` en un navegador. Haz clic para iniciar la partida y volver a impulsar el personaje. El marcador muestra la puntuación actual y la mejor de la sesión.

## Dependencias y límites

El HTML carga una fuente de Google Fonts e imágenes alojadas externamente en i.ibb.co; necesita acceso a esos recursos. La mejor puntuación está en memoria y se reinicia al recargar.

Ejemplo de aprendizaje. No hay proceso de compilación, servidor de aplicación ni pruebas automatizadas.
